Brave LLM Context — CORS test

Paste your API key and (once deployed) your relay URL, then tap Test 3 to check the full chain: browser → relay → Brave. That is exactly the path the TypingMind plugin will use.

Both fields are remembered in this browser. The key is only ever sent to api.search.brave.com, directly or via your relay.

Reading the result
• Green "chain works" → everything is fine; set PROXY_PREFIX in the plugin and you are done.
• HTTP 401 → chain works, key rejected (double-check it).
• HTTP 403 from Brave → chain works, but your plan/token may not include the LLM Context product.
• Red "blocked" → the relay isn't deployed correctly or the URL is wrong.
