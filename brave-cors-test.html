Brave LLM Context — CORS test

This page makes the same browser requests the TypingMind plugin makes, and reports whether the browser blocks them. Run both tests.

The key is only stored in this browser, for this page, to pre-fill next time. It is sent only to api.search.brave.com.

How to read the results
• Both green → CORS is fine, the plugin works as-is (no proxy).
• Test 1 green, Test 2 red → Brave's preflight blocks the custom header → you need the small relay I can write for you.
• Test 1 red → Brave blocks cross-origin calls entirely → relay needed.
